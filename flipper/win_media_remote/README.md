# Win Media Remote

The Flipper Zero shows what's playing on a Windows PC, received over Bluetooth LE: title, artist, album, progress, and cover art when available. The Flipper's buttons pause or resume, change tracks, and adjust the PC's system volume.

## Requirements

- A Windows 10/11 PC with Bluetooth LE running the [Windows Media Remote companion](https://github.com/ostap49/windows-media-remote). The Flipper app alone does nothing without it.
- An app or browser tab that appears in Windows media controls.

## Setup

1. Install and launch Win Media Remote from the Bluetooth category.
2. Start the companion on the PC.
3. Confirm the pairing code on the Flipper when prompted. USB is only needed for installation.

## Controls

- OK: play or pause.
- Left and right: previous or next track.
- Up and down: PC system volume.
- Hold Back: exit the app.
